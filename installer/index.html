📖 Hướng Dẫn Tải Lên Host & GitHub Nhanh:

  1. Shared Hosting / cPanel: Nén thư mục dist/ thành file ZIP, tải lên thư mục public_html trên cPanel và giải nén (tệp .htaccess đã được đóng gói sẵn để xử lý định tuyến SPA).
  2. GitHub Repo Mới: Tạo kho lưu trữ mới trên GitHub, chạy git remote set-url origin <URL> và git push -u origin main.
  3. Vercel / Netlify / Cloudflare Pages (Miễn phí 100%): Kết nối trực tiếp với GitHub repo của bạn, chọn Framework là Vite và nhấn Deploy.
